# Student Management & Performance Database

**Created by:** Stephin Biji  
**Technology:** MySQL / SQL  
**Project type:** Relational database practice project

## What this project demonstrates
- Relational database design
- Primary and foreign keys
- Multiple related tables
- INSERT, UPDATE and DELETE
- SELECT and WHERE
- ORDER BY
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- COUNT, AVG and MAX
- Basic subqueries
- Sorting and reporting queries

## Database structure

`departments`
→ Stores department information.

`students`
→ Stores student details and connects students to departments.

`courses`
→ Stores course details and connects courses to departments.

`enrolments`
→ Connects students and courses and stores semester marks.

## How to run
1. Install MySQL / MySQL Workbench.
2. Open `Stephin_Student_Management_Database.sql`.
3. Run the complete script.
4. The database `stephin_student_db` will be created automatically.
5. Run the demonstration queries at the bottom to explore the data.
